\## Justificación del modelo

Escogimos cada clase, atributo y método mediante el análisis del caso: valoramos los verbos como métodos, los sustantivos como clases (si además se les atribuían características) y las características como atributos. Cada clase, atributo y método está en la lectura; no incluimos nada que no estuviera en el caso. La única clase que no cuenta con métodos es Movimiento, porque la usamos como un registro: solo guarda lo que sucedió, y quien actúa con esa información registrada es la Cooperativa.

El único recurso de IA que usamos fue para que nuestros diagramas se vieran más estéticos. Usamos draw.io para hacer cada diagrama, pero no estábamos convencidos de la parte estética, por eso los pasamos a Gemini para ver si nos daba un resultado que nos gustara, y así fue.

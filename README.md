&#x20;Justificación del modelo



Escogimos cada clase atributo y método mediante el análisis del caso, valorábamos los verbos como métodos, los sustantivos como clases (si además se les atribuían características) y como atributos las características. Cada clase, atributo y método está en la lectura no incluimos nada que no estuviera en el caso. La única clase que no cuenta con métodos es la clase de movimientos y esto se da porque lo usamos como un registro, ya que solo guarda lo que sucedió, y el que actúa con esa información registrada es la Cooperativa.

Intentamos incluir todos los datos que se nos daban en el enunciado, los que descartamos fueron porque eran sinónimos de otros.
